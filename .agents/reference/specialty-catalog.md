# Catálogo de especialidades

| Skill | Alcance |
|---|---|
| `architecture` | runtimes, límites, servicios y fuentes de verdad |
| `backend-database` | Java, Spring, PostgreSQL, Flyway y RLS |
| `frontend` | Next.js, React, API cliente y estado remoto |
| `design-ux` | sistema visual, accesibilidad y flujos de interfaz |
| `ux-testing` | evaluación de experiencia implementada |
| `product-thinking` | problema, valor, alcance y métricas |
| `pm-planning` | briefs, issues, epics y planes verificables |
| `skill-audit-planning` | auditoría previa a build |
| `skill-code-review` | revisión de diffs y riesgo de regresión |

Las skills `wf-*` orquestan el ciclo —incluida la revisión agregada `$wf-review-ships`— y las `pm-*` exponen operaciones concretas.
