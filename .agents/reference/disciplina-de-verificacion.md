# Disciplina de verificación

Una afirmación necesita evidencia reproducible: comando y resultado, prueba automatizada, inspección de ruta/línea o recorrido manual descrito. Distingue `pasó`, `falló`, `bloqueado` y `no ejecutado`.

Empieza focalizado y termina con la puerta del área. No ocultes errores previos del repositorio: sepáralos del cambio y explica cómo se verificó esa atribución. No reduzcas cobertura para obtener verde.
