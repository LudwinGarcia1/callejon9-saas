# Stack frontend verificado

- Next.js 15.5.22 con App Router y Turbopack.
- React 19.1 y TypeScript 5.
- TanStack Query 5 para datos remotos.
- Tailwind CSS 4, shadcn 4 estilo `radix-nova`, Radix UI, Lucide y Sonner.
- pnpm 10.28.2 como único package manager.

Las rutas públicas son `/`, `/login` y `/signup`. Bajo `(authenticated)` están `/admin`, `/waiter`, `/waiter/order/[id]`, `/kitchen`, `/cashier`, `/history`, `/analytics` y `/platform`.
