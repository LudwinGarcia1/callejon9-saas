# Ship

Sigue `workflow/workflow.md`, sección `$wf-ship`. Verifica árbol, alcance, revisión, pruebas y docs. No hagas commit, push, PR, merge ni transición de Linear por inferencia. Nunca muevas un issue a Done sin una revisión aprobada registrada para ese cambio; sin ella, el issue se queda en In review. Si una puerta está bloqueada, presenta el comando, causa y riesgo residual.
