# Auditoría de plan

Compara cada criterio con pasos, archivos y pruebas. Revisa especialmente: autorización por rol, RLS, transacciones, migraciones, concurrencia, contratos backend/frontend, estados UX, datos existentes, rollback operativo y documentación.

Clasifica hallazgos como bloqueante, importante o mejora. Para cada uno incluye evidencia y corrección concreta. Termina con veredicto `listo`, `listo con ajustes` o `no listo`; no apruebes un plan basado solo en intención.
