# Diseño y UX

1. Inspecciona primero la pantalla, `frontend/src/app/globals.css`, `frontend/src/lib/tenant-theme.ts` y componentes cercanos.
2. Conserva tokens OKLCH, tipografías, radios, densidad, iconos Lucide y componentes shadcn existentes.
3. Organiza por tarea del rol, no por estructura técnica. Mantén acciones principales visibles y destructivas protegidas.
4. Diseña explícitamente loading, vacío, error, éxito, deshabilitado y permisos.
5. Valida contraste, labels, foco, teclado, targets táctiles, zoom y anchos móvil/escritorio.
6. Implementa con tokens semánticos; evita colores hex ad hoc y componentes duplicados.

Entrega la jerarquía propuesta, estados, archivos afectados y una lista breve de verificación visual.
