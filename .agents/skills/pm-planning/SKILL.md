# Planeación

1. Lee `AGENTS.md`, `workflow/project-config.yaml` y el contexto de producto necesario.
2. Inspecciona los archivos reales antes de estimar alcance.
3. Define problema, actor, resultado, alcance, fuera de alcance y supuestos.
4. Escribe criterios Given/When/Then observables, incluidos permisos, tenant, error y datos históricos cuando apliquen.
5. Descompón verticalmente por comportamiento entregable; explicita dependencias y secuencia.
6. Asigna archivos probables, estrategia de pruebas y puertas de calidad.
7. Si Linear no está habilitado y verificado, genera el artefacto local sin mutar Linear.

Un plan no está listo si exige decisiones de producto durante la implementación o si sus pruebas no demostrarían los criterios.
